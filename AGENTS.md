# Agenda Prototype

Shared project folder. Open this directory in Cursor, Claude Code, or ChatGPT Codex. The files here are the source of truth.

## How to use this folder

- Keep project files in this directory, not in a tool-specific location.
- Read this file at the start of a session and follow it.
- Git is how the work moves between machines and tools. Commit here, then push or pull the GitHub repo.

## Tool notes

- Cursor: open this folder as the workspace.
- Claude Code: run it from this folder. `CLAUDE.md` points here.
- ChatGPT: use Codex or a connector pointed at this folder. A ChatGPT Project in the browser is separate and does not replace this directory.
